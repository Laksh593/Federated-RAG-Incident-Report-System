Inference Process:
1. Load trained model from checkpoint
2. Extract 16 equally-spaced frames from video
3. Resize to 224×224
4. Normalize to [-1, 1]
5. Pass through 3D CNN → get 512-dim features
6. Apply MIL + Temporal Attention
7. Output predicted anomaly class + confidence

RAG Pipeline (Knowledge-Based Report Generation)
Purpose: Generate contextual, policy-aligned incident reports using knowledge base
Component 1: Retriever (Hybrid Search)
Create Knowledge Base: for all the incident type
Retrieval Pipeline:
1. Chunk Documents: Break policy files into 512-char chunks with overlap
2. Embed Chunks:
   * Generate embeddings using sentence-transformers (all-MiniLM-L6-v2)
   * Store in ChromaDB (persistent vector database)
3. Hybrid Search (Combines 2 methods):
   * Dense Search (Vector): ChromaDB cosine similarity search
   * Sparse Search (BM25): Keyword/term frequency matching
   * Fusion: Reciprocal Rank Fusion (RRF) combines both rankings
4. Re-ranking (Cross-Encoder):
   * Top 15 candidates from hybrid search
   * Re-ranked by cross-encoder/ms-marco-MiniLM-L-6-v2
   * Returns top 5 most relevant
